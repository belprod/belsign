# Politique de sécurité

## Versions maintenues

Les correctifs de sécurité sont publiés pour la **dernière version** de Belsign. Mettez toujours à jour vers la version la plus récente : envoyez simplement la nouvelle archive par FTP, la base se met à jour automatiquement.

| Version | Correctifs de sécurité |
|---|---|
| 1.0.x | ✅ |

## Signaler une faille

**Ne créez pas de ticket public.** Utilisez le signalement privé de GitHub :

1. Onglet **Security** de ce dépôt.
2. **Report a vulnerability**.
3. Décrivez le problème, la version concernée et les étapes pour le reproduire. Indiquez aussi son impact : qui peut faire quoi.

Nous accusons réception sous 7 jours et vous tenons informé jusqu'à la correction. Merci de ne pas rendre la faille publique avant la publication du correctif. Avec votre accord, vous serez crédité dans le changelog.

## Mesures en place

Les protections intégrées à l'application, et les bonnes pratiques à la charge de l'exploitant (HTTPS, sauvegardes, comptes), sont décrites dans [docs/securite.md](docs/securite.md).
